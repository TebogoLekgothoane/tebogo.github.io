# Personal Portfolio Website

A modern, interactive portfolio website for **Tebogo Eveline Lekgothoane** — showcasing skills, experience, education, projects, and achievements. Built with **HTML, CSS, and JavaScript** for fast performance and easy customization.

- **Animated intro** with typewriter effect

- **Particle background** with dynamic connections
- **Experience roadmap** with interactive timeline

- **Certifications carousel** with auto-play
- **Contact form** with mailto integration
- **Responsive design** optimized for all devices
- **Smooth scroll animations** and reveal effects
- **Dark theme** with modern UI

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom styling with animations
- **JavaScript (ES6+)** — Interactive features and animations
- **Spline 3D** — Interactive 3D scene viewer

## Run Locally

### Option A: Quick Start
Double-click `index.html` to open in your browser.

### Option B: Local Server (Recommended)
Using a local server avoids caching issues and enables proper asset loading:

**VS Code:**
1. Install the "Live Server" extension
2. Right-click `index.html` → "Open with Live Server"

**Command Line:**
```bash
# Python 3
python -m http.server 8080

# Node.js (with http-server)
npx http-server -p 8080

# PHP
php -S localhost:8080
```

Then open `http://localhost:8080` in your browser.
